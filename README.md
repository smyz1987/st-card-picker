# 🎴 AI 选卡师（st-card-picker）

SillyTavern 扩展：输入你想要的感觉/人设/剧情，AI 从你的全部角色卡中推荐最适合的；还有多种选卡玩法。

## 功能

- **智能匹配**：描述你想玩的感觉（例如"想要温柔病娇的妹妹，前期甜后期黑化"），AI 综合角色的人设、标签、开场白推荐 Top N 张，附匹配度和推荐理由
- **随机骰子**：从角色库随机抽一张
- **心情模式**：预设"甜宠 / 黑深残 / 悬疑 / 日常 / 冒险 / 科幻 / 治愈"，本地关键词筛出候选后随机抽一张
- **盲盒**：只给你看开场白片段，猜猜是谁，点击揭晓
- 所有推荐结果可展开查看人设摘要和开场白

## 安装

SillyTavern → 扩展 → 安装扩展 → 输入仓库地址：

```
https://github.com/smyz1987/st-card-picker
```

## 使用

1. 右下角悬浮 **🎴** 按钮打开选卡师
2. 先到「设置」页配置 API（OpenAI 兼容格式）：
   - API Base URL（如 `https://api.example.com`，自动补 `/v1`）
   - API Key
   - 模型名
   - 推荐数量（1-10）
3. 切到对应玩法页使用

## 说明

- API 为扩展独立配置，不影响酒馆主配置
- 角色卡数据直接读取酒馆已加载的角色库，无需额外扫描
- 角色较多时 AI 匹配会自动压缩清单保证请求不超长
